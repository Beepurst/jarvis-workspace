# Messages de demande d'avis

> Remis à chaque livraison, toutes formules, et utilisés chaque mois dans le Suivi avis.
> Le client les envoie **lui-même**, depuis son téléphone ou sa boîte mail, à ses propres clients. Kleak n'envoie rien en son nom.

Les éléments entre accolades sont à remplacer pour chaque client :

| Variable | Exemple |
|---|---|
| `{prénom du client final}` | Mme Lefèvre, Julien |
| `{prénom}` | Thomas (celui qui signe le message) |
| `{entreprise}` | Garnier Plomberie Chauffage |
| `{prestation}` | le remplacement de votre chauffe-eau, votre séance, la rénovation de votre salle de bain |
| `{métier}` | un plombier, une esthéticienne, un cabinet comptable |
| `{téléphone}` | le numéro affiché sur le site |
| `{lien}` | le lien d'avis Google de la fiche (voir `README.md`, étape 1) |

On adapte au client avant de livrer : tutoiement ou vouvoiement selon sa façon de parler à ses clients, « je » pour un indépendant, « nous » pour une équipe, et le mot juste à la place de `{prestation}` (chantier, intervention, séance, commande, rendez-vous).

---

## 1. SMS ou WhatsApp

À envoyer le jour même ou le lendemain de la prestation. C'est le message qui marche le mieux parce que le client final l'ouvre tout de suite.

```
Bonjour {prénom du client final}, c'est {prénom} de {entreprise}. Merci encore pour votre confiance pour {prestation}. Si vous avez deux minutes, un avis sur Google nous aiderait beaucoup : {lien}
Bonne journée !
```

Version courte, pour un client qu'on connaît bien :

```
Bonjour {prénom du client final}, merci pour aujourd'hui. Si vous avez un moment, vous pouvez laisser un avis sur Google ici : {lien}
{prénom}
```

## 2. Email

Pour les clients qui ont donné leur email plutôt que leur numéro, ou pour les métiers où l'échange se fait par mail.

**Objet :** Votre avis sur {entreprise}

```
Bonjour {prénom du client final},

Merci encore de nous avoir fait confiance pour {prestation}.

Si vous avez deux minutes, votre avis sur Google nous aiderait beaucoup. Il aide aussi les personnes qui cherchent {métier} près de chez elles à savoir à qui s'adresser.

Laisser un avis : {lien}

Bonne journée,
{prénom}
{entreprise}
{téléphone}
```

## 3. Relance

Une seule, 5 à 7 jours après, uniquement si aucun avis n'est arrivé. Pas de deuxième relance.

```
Bonjour {prénom du client final}, je me permets de revenir vers vous pour l'avis Google, ça prend une minute : {lien}
Merci d'avance, {prénom}
```

## 4. À dire de vive voix, avec le QR code

En fin de prestation, en tendant la carte ou en montrant l'affichette :

> « Si vous avez une minute, vous pouvez nous laisser un avis sur Google, il suffit de scanner le code avec votre téléphone. »

---

## Ce qu'on n'écrit jamais

Ces formulations sont contraires aux règles de Google (avis sollicités de façon sélective ou contre une contrepartie) et peuvent faire supprimer les avis, voire suspendre la fiche :

- « Si vous êtes satisfait, laissez-nous un avis » : on demande à **tous** les clients, contents ou pas.
- « Laissez-nous 5 étoiles » : on ne suggère pas de note.
- « Un avis contre 10 % sur votre prochaine facture », un cadeau, un tirage au sort : aucune contrepartie.
- Un avis rédigé à la place du client, même avec son accord.
